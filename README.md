# ⚔️ Sekiro: Text-Based Shinobi Showdown

A CLI Python action game inspired by *Sekiro: Shadows Die Twice*. Experience fast-paced combat built around **Posture**, **Deflecting**, **Mikiri Counters**, and **Perilous Attacks** right inside your terminal.

## 🚀 Features

* **Posture System:** Lowering HP reduces recovery, but filling the Posture bar leads to an instant Shinobi Deathblow.
* **Perilous Attacks ($危$):** React to Thrusts and Sweeps using specific countermeasures (Mikiri Counter vs. Jump Kick).
* **Parry & Deflect:** Timed defensive choices allow you to turn enemy strikes into posture damage against them.
* **Healing Gourd:** Finite healing resources force strategic timing between attacking and recovering.

## 🛠️ Requirements

* Python 3.8 or higher
* Standard Python libraries (`random`, `time`, `unittest`)
